## 🚧 待实现功能

### 1️⃣ 浏览器内核适配（关键）

**问题**: Camoufox 基于 Firefox 桌面版，不支持移动端

**解决方案**: 使用 Chromium 内核模拟移动端

#### 方案 A: fp-chromium 内核扩展（推荐）
```python
# app/kernels/fp_chromium_kernel.py 新增移动模式支持

async def start(
    profile_id: str,
    fingerprint_data: dict,
    target_os: str,  # "android" or "ios"
    ...
):
    if target_os in ("android", "ios"):
        # 注入移动端 User-Agent
        ua = fingerprint_data.get("navigator", {}).get("userAgent")
        
        # 设置移动端viewport
        screen = fingerprint_data.get("screen", {})
        viewport = {
            "width": screen.get("width"),
            "height": screen.get("height"),
        }
        
        # 启用移动端特征
        context_args = {
            "user_agent": ua,
            "viewport": viewport,
            "device_scale_factor": screen.get("devicePixelRatio", 2.5),
            "timezone_id": timezone_from_ua(ua),
            # 移动端特有
            "touch": True,
            "has_touch": True,
        }
        
        # 注入移动端 CDP 事件
        cdp = await context.new_cdp_session(page)
        await cdp.send("Emulation.setTouchEmulationEnabled", {
            "enabled": True,
            "maxTouchPoints": 10,
        })
        
        return {...}
```

```bash

  -H "Content-Type: application/json" \
  -d '{
    "name": "Samsung S24 测试环境",
    "kernel": "fp-chromium",  # 移动端只能用 Chromium
```
