[AdSupport / IDFA]
  @_OBJC_CLASS_$_ASIdentifierManager
  _OBJC_CLASS_$_ASIdentifierManager
  @_OBJC_METACLASS_$_ASIdentifierManager
  + 主二进制链接 AdSupport.framework
  => 具备读取广告标识符(IDFA) 的能力（具体调用点在加密段，未证实用途）。
  => 注：包内无 NSUserTrackingUsageDescription；iOS 14.5+ 下 ATT 未弹窗即拒绝，
     IDFA 读出为全零。
